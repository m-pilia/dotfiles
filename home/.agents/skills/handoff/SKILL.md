---
name: handoff
description: Summarize the status into a document for another agent to continue the work.
---

Create a handoff document summarizing the status of the current task, so that the work can be continued by a fresh agent. Create the document as YYYY-MM-DD-HH:MM:SS_HANDOFF.md in the root of the current workspace, unless otherwise instructed. Focus on what needs to be done, do not repeat content from already available input artifact nor from output status reports. Redact any sensitive or personally identifiable information.
