---
name: inquisition
description: Relentlessly ask questions to the user about a plan, idea, or decision. Use when the user wants to fully define a topic without leaving room for ambiguity nor interpretation, or when the `inquisition` trigger is used.
---

Do not make any assumptions. If any aspect is unclear, ambiguous, or can be done in different ways, ask the user until every aspect is fully set.

Ask a full round of questions at a time, based on already set prerequisites. After getting answers, gather all unclear, ambiguous, or undefined points and ask a new round of questions. Iterate until everything is fully settled from explicit user input, without assuming anything at all.

The inquisition session is done when the topic is fully defined and nothing is left to assume. Do not start acting or implementing until explicitly instructed by the user to do so.
